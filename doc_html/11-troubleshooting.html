11. Troubleshooting

11.1 Бэкенд/индекс

Симптом Причина Решение
Чат: «Бэкенд недоступен» / источники пустые Ядро не запущено или RAG_API_URL неверный Запустить ядро, проверить http://127.0.0.1:11455/rag/health; в админке — статус бэкенда
Ядро не отвечает (порт 11455) Процесс ядра не стартовал / упал Лог ядра; запустить python -X utf8 app.py; проверить, что в settings.json корректный url бэкенда
Админка показывает «status_backend: false» Ollama/LM Studio не запущен или занят другой model Запустить бэкенд, в админке нажать проверку моделей
Ответы «выдуманы», без контекста similarity_top_k мал, документов в индексе нет, тема далеко от корпуса Пересинхронизировать («Сброс + синхронизация»), увеличить контекст/top_k
is_syncing: true навсегда Папка sync_folders недоступна по сети/вагоне Проверить пути папок, сетевые диски (резервирование на линию UNC)

11.2 Word COM / парсеры

Симптом Причина Решение
Зависание при индексации .docx Параллельный вызов Word COM (второй поток/приложение) В коде всё сериализовано _WORD_LOCK; не держите открытыми Word вручную во время синхронизации
.doc не парсится Нет Word / COM недоступен Установить Word; проверить на другом exe-режиме+Word наличие
.pdf не конвертируется FineReader 15 не найден (C:\Program Files (x86)\ABBYY FineReader 15\FineCmd.exe) Установить ABBYY; путь жёсткий в коде pdf_parser.py
Страницы считаются 0 Таблица без Word COM… фактически — открыт только через COM; 0 возникает при незакрытых диалогах Убедиться, что Word не в «безопасном режиме» и не спросил пользователя
Кириллица в .docx выходных битая Запуск без -X utf8 Всегда python -X utf8 app.py/generate_memos.py

11.3 Web UI

Симптом Причина Решение
«Порт 80: требуется администратор» Порт 80 слушают только от администратора $env:PORT="5000" затем app.py
POST /api/memo/docx → 500 «Шаблон … не найден» MEMO_TEMPLATE_DIR указывает не туда; в frozen — нет _internal/docx_templates/mmo.dotx В frozen: положить /verify _internal\docx_templates\mmo.dotx; в dev: MEMO_TEMPLATE_DIR=<корень>/docx_templates
Браузер держит старый JS MEMO_JS_VERSION не бампнут Поднять версию в config.py(Web UI) и перезапустить
Нет кнопки «Скачать .docx» (500) — варианты из mmo.dotx без полей Шаблон не содержит {{ body }} или битая загрузка POST /api/admin/memo/template/reload; скачать дефолтный mmo.dotx (deploy)
Чат недоступен, / крутится Фронтенд app.js не стартует из-за JS-ошибки F12 → Console; node --check на JS; проверить ?v= версии
Скачанный служебка с пустым {{ body }} Тело пустое, а шаблон ожидает абзац {{ body }} — это норм, если поле пустое в мастере Перед скачиванием заполнить вариант тела

11.4 Сборка / frozen

Симптом Причина Решение
ValueError: Unknown encoding cl100k_base В frozen нет tiktoken_ext build.spec: datas += collect_data_files("tiktoken_ext"); пересобрать
Мусор в логах консоли exe stdout/stderr в cp1251 В hook_runtime.py переопределить sys.stdout/-stderr на UTF-8
Web UI frozen не находит БД DATABASE_URL указывает в _internal, а не рядом с exe hook_runtime.py должен ставить <exe_dir> (путь к sys.executable, а не _MEIPASS)
Старая сборка не подхватывает новый шаблон Шаблон в _internal старой версии Пересобрать Web UI или вручную заменить _internal\docx_templates\mmo.dotx

11.5 Индекс/кэш

Симптом Причина Решение
Индекс показывает старые файлы после удаления из out/ Удаление файлов сейчас не детектируется (deleted=[] в sync_index) «Сброс + синхронизация» в админке или удалить .cache/ ядра рядом с exe/в cwd
document_count завышен В доксторе остались узлы удалённых Полный reset sync
Слишком долгая первая индексация Чанкинг+эмбеддинг всех файлов Норм при out/ из 50 файлов: ~1–3 мин
