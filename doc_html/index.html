RAG System Docs

Документация RAG System + RAG System Web UI

Репозиторий из двух Python-проектов: ядро RAG (Flask API, порт 11455, префикс /rag) и веб-интерфейс (Flask Web UI). Здесь собрано полное описание: архитектура, API, схема БД, мастер служебной записки, установка, тесты, сборка, troubleshooting и соглашения по git. Все страницы — HTML-версии файлов из папки doc/; диаграммы Mermaid рендерятся в браузере.
